# Revisor E-GO Cars

Panel local para revisar la web paso a paso: vista desktop + móvil, checklist de funciones y UX/UI, y escaneo SEO automático.

## Abrir
- Mac: doble clic en `INICIAR.command` (la primera vez: clic derecho → Abrir).
- O en la Terminal: `node checker/server.js` y entra a http://localhost:4321

Requiere Node 18 o superior. No instala nada.

## Usar
1. Escribe la dirección de la web (ej. `http://localhost:3000` o `https://tusitio.cl`) y aprieta **Cargar página**.
2. Pestaña 2: marca cada punto en Desktop y Móvil. "Cómo revisarlo" explica qué mirar. Los checks quedan guardados en el navegador.
3. Pestaña 3: **Escanear ahora** revisa SEO, enlaces rotos, redes sociales y más, con qué arreglar.
